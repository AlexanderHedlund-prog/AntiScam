# AntiScam v0.9 — дополнительная проверка неизвестных файлов

Сохраняет проверку ссылок, Google Safe Browsing v5, собственный статический анализ файлов и подключаемый ClamAV из v0.8.

## Что изменилось

- Сначала AntiScam проверяет файл локально, затем (по согласию) запрашивает существующий отчёт VirusTotal по SHA-256.
- Если отчёт не найден, **по отдельному явному согласию** можно отправить *сам файл* в VirusTotal на новый анализ, **только если владелец сайта разрешил эту функцию**.
- VirusTotal возвращает ID анализа; пользователю показывается кнопка «Узнать результат». Сканирование может идти несколько минут. Пока оно не завершено, файл не объявляется безопасным.
- Загрузка ограничена **8 МБ**, число новых отправок ограничено до **8 в сутки на процесс**; общий лимит запросов VirusTotal — не более 3/мин на процесс. Несколько экземпляров Render требуют внешнего общего лимитера (например, Redis). Перезапуск процесса сбрасывает счётчики.
- Сам AntiScam **не хранит содержимое файла** между запросами. Номер анализа и случайный токен ожидания хранятся в оперативной памяти до 30 минут. При перезапуске сервера токен перестаёт работать — пользователь может снова проверить SHA-256 позднее.
- На экране явно различаются: «вирус обнаружен», «есть признаки риска», «известных угроз не обнаружено» и «данных недостаточно».

## Очень важное предупреждение о конфиденциальности и лицензии

**Обычная публичная загрузка в VirusTotal может сделать образец доступным его сообществу и партнёрам.** Не отправляйте личные фотографии, презентации с персональными сведениями, частные письма, договоры или любые секретные документы. Отправляйте только собственные специально подготовленные **не конфиденциальные** тестовые файлы с необходимыми правами.

У бесплатного публичного API VirusTotal ограничения по количеству обращений и условия использования. Он предназначен для **некоммерческого / исследовательского использования** и **не должен выступать заменой антивирусу**. Прежде чем включать функцию на публичном сайте, владелец обязан проверить применимость условий и при необходимости получить разрешение или коммерческую лицензию. Интеграция по умолчанию отключена.

Официальная документация: https://docs.virustotal.com/reference/files-scan , https://docs.virustotal.com/reference/analysis , https://docs.virustotal.com/docs/difference-public-private , https://docs.virustotal.com/v2.0/reference/getting-started

## Как обновить публичный AntiScam

1. Скачай `AntiScam_v0.9_обновление_GitHub.zip` и распакуй его.
2. Открой https://github.com/AlexanderHedlund-prog/AntiScam → **Add file → Upload files**.
3. Перетащи **содержимое** архива в репозиторий так, чтобы `app/main.py` и `app/vt_file_submission.py` находились внутри единственной папки `app` в корне. Не загружай ZIP целиком.
4. Нажми **Commit changes**. Дождись успешного автоматического обновления Render.
5. На https://antiscam-xj4u.onrender.com/health проверь версию `0.9.0`.
6. **Не меняя ничего в настройках**, проверь обычную загрузку PDF — хеш-проверка и собственный анализ должны работать как раньше.

## Как включить возможность нового сканирования (только если разрешено условиями VT)

1. Проверь, что ты вправе использовать публичный API VirusTotal в таком проекте; для публичного сервиса, заменяющего антивирус, бесплатный ключ может не подходить.
2. В Render → AntiScam → **Environment** добавь переменную `VT_FILE_UPLOAD_ENABLED` со значением `true`. Существующая переменная `VIRUSTOTAL_API_KEY` должна быть настроена. Нажми Save, deploy. **Никогда не добавляй API-ключ в GitHub**.
3. Открой страницу **«Проверить файл»**. Появится дополнительная галочка «Если отчёта нет — отправить мой файл на новое сканирование VirusTotal» с предупреждением о публичной передаче файла.
4. Отправляй **только собственный не конфиденциальный тестовый файл** размером до 8 МБ и только если согласен на возможное публичное распространение образца.
5. Если готового отчёта не было, появится сообщение об отправке и кнопка **«Узнать результат»**. Подожди минуту и нажми кнопку. При нехватке квоты, отсутствии ответа или неполных данных сайт не назовёт файл безопасным.
6. Чтобы отключить функцию, в Render установи `VT_FILE_UPLOAD_ENABLED=false` и сохрани с перезапуском. Поиск отчётов по SHA-256 останется доступным.

**ClamAV:** по-прежнему не запускается на бесплатном Render сам собой. Для локального сканирования без отправки образца внешним сервисам потребуется отдельный сервер с ClamAV.

## Локальный запуск и тесты

Python 3.11+:

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```

**Ограничения:** 100% гарантии отсутствия вирусов нет. При развертывании для большого числа пользователей необходимы независимый аудит безопасности, разделение нагрузки и долговременные общие лимитеры. Публичная отправка файлов должна быть согласована с условиями поставщика.
