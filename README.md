# AntiScam v1.3.1 — ссылки, файлы и краткие отчёты

Бесплатный некоммерческий образовательный проект. Адрес действующего сайта: https://antiscam-xj4u.onrender.com/

## Что добавлено в v1.3.1

1. **Фишинговые страницы:** по отдельному разрешению в ограниченном HTML-фрагменте определяются формы отправки паролей на другой домен, парольные формы по HTTP, скрытые iframe, автоматические переходы, некоторые приёмы сокрытия скриптов и несоответствие названия известного сервиса домену страницы. Никакой JS подозрительной страницы не запускается.
2. **Файлы по URL:** отдельная галочка «Если ссылка ведёт на файл». Сервер безопасно скачивает **только публичный файл до 2 МБ** после согласия. Файл статически проверяется на формат, опасные расширения, подозрительные признаки, архивные вложения и хеш SHA-256. Он **не исполняется, не сохраняется на диск проекта и не передаётся целиком в VirusTotal**. Большие, недоступные, сжатые HTTP-ответы или обычные веб-страницы возвращают «не удалось проверить», а не «безопасно».
3. **PDF/Office/архивы:** проверяются дополнительные активные PDF-элементы, DDE в небольших Office XML и метаданные архивов. ZIP частично просматриваются с ограничениями против ZIP-бомб; вложенные ZIP и зашифрованные элементы отмечаются как непроверенные. **RAR/7z не распаковываются**; определяется только формат, без гарантии антивирусного анализа.
4. **Цепочка HTTP-перенаправлений:** в дополнительном разделе «Куда ведёт ссылка» видно пройденные домены и протоколы без секретных путей и параметров. Переходы на внутренние адреса запрещены; максимум три перехода.
5. **Поддельные домены:** дополнительные эвристики для IDN/смешанных алфавитов и опечаток в именах известных сервисов рядом со словами авторизации. Они могут ошибаться и не доказывают мошенничество.
6. **Отчёт в PDF:** в результате ссылки и файла появилась кнопка «Сохранить отчёт в PDF», которая открывает диалог печати браузера. Выберите **«Сохранить как PDF»**. Для создания отчёта не нужна сторонняя служба и не передаются дополнительные данные.

На главной странице дополнительные сетевые проверки скрыты в раскрывающемся разделе, чтобы не загромождать интерфейс. Отдельное согласие на отправку файлов в VirusTotal, настройки API и компактный дизайн v1.2 сохранены.

## Установка обновления на GitHub → Render

1. Скачайте `AntiScam_v1.3.1_обновление_GitHub.zip` и распакуйте на компьютере.
2. Откройте https://github.com/AlexanderHedlund-prog/AntiScam → **Add file → Upload files**.
3. Загрузите **содержимое распакованной папки** в корень репозитория. Должны получиться пути `app/main.py`, `app/remote_file.py`, `app/page_inspector.py`, `app/scanner.py`, `app/static/index.html` и т. д. **Без дополнительной папки AntiScam**.
4. Нажмите **Commit changes**. Дождитесь автопубликации Render и статуса **Live**. Если автопубликация отключена, запустите Deploy latest commit.
5. Откройте https://antiscam-xj4u.onrender.com/health — ожидается `"version": "1.3.1"`.
6. Вставьте `https://example.com/` для безопасного теста URL без скачивания. Дополнительные функции проверяйте на **своём небольшом публичном тестовом файле**, без секретов и личных данных.

`requirements.txt` и ключи в Render менять не требуется. Переменные Google Safe Browsing, VirusTotal и `VT_FILE_UPLOAD_ENABLED` остаются прежними. Никакие секреты в архив не включены.

## Меры безопасности и ограничения

- Проверка внешних сайтов и загрузка файла — **только по согласию**. Сайт назначения увидит сетевой запрос. Не сканируйте приватные ссылки с токенами и персональными данными.
- Доступ только через HTTP/HTTPS, стандартные порты, проверку публичности адресов DNS с закреплением IP на каждом соединении; запрещены внутренние/локальные IP, подозрительные перенаправления; ограничены размер, время и параллельные скачивания.
- Проверка ссылок на файлы не отправляет целый файл в VirusTotal. Публичная отправка через вкладку «Проверить файл» остаётся **отдельным добровольным действием**, с соглашением и действующими квотами API.
- Статический анализ **не является антивирусом**: «угроз не обнаружено» не значит «файл точно безопасен». Сервис не исполняет файлы и не имитирует полноценный браузер или изолированную песочницу.
- Текущая защита от перегрузки и SSRF снижает риски, но публичный сайт требует независимого аудита, изоляции инфраструктуры, мониторинга и внешних лимитов перед массовым распространением.
- PDF-отчёт формируется печатью клиента: итог зависит от браузера и настроек печати.

## Разработка

```bash
pip install -r requirements.txt
pip install -r requirements-dev.txt
pytest -q
uvicorn app.main:app --reload
```

Все автоматические тесты локальные и не отправляют пользовательские файлы в VirusTotal. Для безопасности в тестах загрузка по URL подменяется контролируемыми ответами, реальную работу с произвольными опасными URL не проверяли.


## Изменения v1.3.1 (отчёты)

- Один главный вывод вместо двух повторяющихся крупных баннеров.
- Подтверждённая загрузка файла по ссылке теперь отображается как реальный анализ загруженных байтов, а не предположение по расширению.
- Предупреждение явно различает статическую проверку скачанного файла и просмотр HTML.
- Печатный отчёт не разрывает карточки VirusTotal/Google Safe Browsing между листами.
- Без изменений: API-ключи, лимиты запросов, отправка файлов только с отдельного согласия, собственный анализ.
