# 🛡️ AntiScam v0.3 — проверка ссылок и файлов

**На Windows:** распакуйте архив и запустите `START_ANTISCAM_WINDOWS.bat`.
**Новичкам:** начните с файла `НАЧНИ_ЗДЕСЬ.txt` (по-русски: GitHub и Render).

**Работающий исходный код сайта на русском языке**. Три страницы: `/` — проверка ссылок, `/file` — загрузка файла, `/about` — информация о проекте. Дизайн: тёмная шапка, коричневый градиент, зелёные кнопки, крупные скруглённые карточки. На телефоне страницы и формы адаптируются под узкий экран.

> **Важно:** это инструмент предварительной проверки, **не полноценный антивирус**. Без подключённых внешних API сайт не определяет, есть ли в файле вирус, а только изучает формат и некоторые признаки риска. Даже «известных угроз не найдено» **не означает, что файл или ссылка безопасны**.

## Две основные проверки

**Ссылки:** поле ввода URL, признаки опасности в адресе; по отдельному согласию пользователя — запрос к Google Safe Browsing / VirusTotal (если API-ключи настроены), а также безопасный HEAD-запрос для уточнения объявленного сервером формата. HTML-страницы не открываются, файлы по ссылкам не скачиваются.

**Файлы:** загрузка файла до **8 МиБ**, анализ в памяти процесса (фреймворк может временно использовать системный буфер/временный файл для multipart), определение формата по первым байтам и структуре ZIP-контейнера, подсчёт SHA-256 и заметные признаки риска: двойное расширение, неожиданный исполняемый формат, некоторые PDF-активности и макросы Office. Файлы не выполняются, не распаковываются на диск, не хранятся в приложении и **не отправляются целиком** в сторонние сервисы. С согласия пользователя SHA-256 сверяется с **существующим** отчётом VirusTotal. Если хеш отсутствует в базе, вирусный статус остаётся неизвестным. Работа с временными буферами/системным временным хранилищем завершается после обработки запроса.

Скачивать подозрительный файл ради загрузки в AntiScam **не требуется и не рекомендуется**: проверка URL — более безопасный первый шаг. Нельзя обещать, что любой файл безвреден, если он открывается как PDF, презентация или картинка.

## Запуск локально

Требуется Python 3.11 или новее.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
# Необязательно: настройте .env по образцу .env.example
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000 — главную; http://127.0.0.1:8000/file — проверку файла.

## Ключи проверок известных угроз

Скопируйте `.env.example` в `.env` и заполните при необходимости:

```dotenv
GOOGLE_SAFE_BROWSING_API_KEY=
VIRUSTOTAL_API_KEY=
RATE_LIMIT_PER_MINUTE=12
```

Ключи должны храниться **только на сервере**, не в браузере и не в GitHub. Проверка VirusTotal **не** загружает файл — запрашивает только имеющийся отчёт по SHA-256. Учтите условия пользования и лимиты бесплатных API; если ключи недоступны, интерфейс укажет, что база не проверялась.

- Google Safe Browsing v5: https://developers.google.com/safe-browsing/reference/rest/v5/urls/search
- VirusTotal (файл по хешу): https://docs.virustotal.com/reference/file-info
- VirusTotal (URL): https://docs.virustotal.com/reference/url-info

## Публикация через GitHub + Render

1. Создайте репозиторий и загрузите туда **содержимое папки AntiScam** (включая `app/`, `requirements.txt`, `render.yaml` и т. д.). Не выкладывайте файл `.env`.
2. В https://render.com/ выберите **New → Web Service** и привяжите репозиторий.
3. Используйте `render.yaml` (Blueprint) либо задайте команды:
   - Build: `pip install -r requirements.txt`
   - Start: `uvicorn app.main:app --host 0.0.0.0 --port $PORT --no-access-log`
4. В **Environment** при необходимости добавьте API-ключи. Не публикуйте их в чате или репозитории.
5. После развёртывания откройте `/health`, `/`, `/file` и проверьте формы. **Сам ZIP не создаёт работающий публичный сайт** — нужен хостинг.

Для большого публичного запуска перед приёмом файлов от незнакомцев нужны дополнительные меры: обратный прокси с ограничением размера запросов, WAF и общесерверный rate limit, ограничения ресурсов и сети контейнера, антивирусная песочница/изолированный сканер при необходимости, независимая проверка безопасности и политика обработки персональных данных. Текущая версия — **публичный прототип для тестирования**, не готовый высоконагруженный антивирусный сервис.

## Тесты

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```

Автоматические тесты проверяют анализ ссылок и файлов, API, типы документов, опасные расширения, опциональную репутацию по хешу и ограничения на размер.

## Обновление v0.3: Google v5 + подключение внешних проверок

- URL Google Safe Browsing v5 (`urls:search`, вместо устаревшего v4). Сервис соблюдает `cacheDuration` из ответа, кешируя только хеш запроса и результат.
- VirusTotal URL: только **чтение готового отчёта** `/api/v3/urls/{id}`. Никакого автоматического POST/submit URL или файла. Но VirusTotal предупреждает, что запрашиваемые индикаторы могут попадать в его набор данных.
- VirusTotal file: сверка SHA-256 с `/api/v3/files/{sha256}`; байты файла не уходят в VirusTotal.
- Общий мягкий лимит 3 VirusTotal вызова/минуту в пределах **одного Python-процесса**. Несколько процессов/хостов требуют общесерверного распределённого лимитера.
- Добавлен `/api/providers`: показывает, **настроены ли** ключи, но не раскрывает их и не подтверждает, что они действительны.
- При совпадениях Google сайт показывает ссылку «Advisory provided by Google» и уточняет, что речь о вероятной угрозе. Базы могут давать ложноположительные и ложноотрицательные результаты.
- Если бесплатные квоты исчерпаны, ответ становится `error` (а не ложно безопасным).

**Полный пошаговый порядок для Render** находится в `ПОДКЛЮЧИТЬ_API_КЛЮЧИ.txt`.

Использование Google Safe Browsing бесплатно только для **некоммерческих** проектов. Бесплатный VirusTotal API не предназначен для коммерческих проектов и не должен позиционироваться как самостоятельный антивирус. Публичная версия AntiScam остаётся **тестовой**, так как обрабатывает загружаемые извне файлы.
