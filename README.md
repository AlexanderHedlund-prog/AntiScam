# AntiScam v0.8 — статический анализ и подключение ClamAV

Веб-проект на FastAPI с отдельными страницами проверки ссылок и файлов.
Прежние Google Safe Browsing v5, VirusTotal и статический просмотр сайтов сохранены.

## Что добавлено в 0.8

1. **Собственная проверка загруженных байтов** (всегда): обнаруживает отдельные признаки опасных скриптов и маскировки файлов, читает небольшую часть некоторых вложений ZIP/Office без распаковки на диск. Для проверки работы анализатора распознаёт **безвредную тестовую сигнатуру EICAR**, которая НЕ является вирусом. Собственный анализ НЕ является полноценным антивирусом и НЕ распознаёт все вирусы.
2. **ClamAV** (необязательно): если владелец развернёт настоящий ClamAV `clamd` на том же защищённом сервере, AntiScam умеет передавать байты файла по **локальному UNIX-сокету** через официальный протокол `INSTREAM`. Вся загрузка ограничена 8 МБ; никаких произвольных TCP/HTTP-адресов для подключения антивируса нет. Если ClamAV не настроен или недоступен, пользователь видит соответствующий статус и не получает ложный результат «безопасно».
3. Статусы в блоке «Что проверил AntiScam» различают реальную проверку (✓) и непроведённую проверку (?).
4. По согласию пользователя VirusTotal получает **только SHA-256**, не содержимое загруженного файла.

## Важное ограничение хостинга

Официальная документация ClamAV рекомендует для полноценного движка **3 ГБ RAM и более** и несколько ГБ диска. Обычный бесплатный Render с **512 МБ RAM** для него не подходит. После загрузки v0.8 в существующий Render **собственные эвристики работают сразу**, но ClamAV останется «не подключён», пока ты не установишь его на подходящем хостинге. Нельзя просто добавить API-ключ и включить ClamAV.

Не подвергай ClamAV TCP-порт 3310 публичному интернету — протокол не шифруется и не аутентифицирует клиентов. В этой версии AntiScam принимает только путь UNIX-сокета на том же сервере. Если ClamAV будет вынесен на отдельный сервер, понадобится специально разработанный закрытый и аутентифицированный мост (пока не реализован).

## Подключение ClamAV, если владелец использует свой Linux-сервер

1. Установи `clamav-daemon` и `clamav-freshclam` из репозитория дистрибутива и обнови базы сигнатур. Убедись, что `clamd` действительно запущен, а сокет доступен пользователю FastAPI.
2. В закрытых переменных окружения укажи `CLAMD_SOCKET_PATH=/run/clamav/clamd.ctl` **только если именно там расположен твой действующий UNIX-сокет**. Путь зависит от конфигурации.
3. Установи лимит сканирования ClamAV не менее размера загружаемых файлов (до 8 MiB) и изолируй сам процесс/демон; проводи аудит безопасности и регулярно обновляй сигнатуры.
4. Перезапусти FastAPI и попробуй проверку собственного безопасного файла. В разделе «ClamAV» должно появиться «проверил байты файла». Результат не гарантирует отсутствие неизвестных угроз.

Здесь нет установки ClamAV на бесплатный Render автоматически.

## Как обновить существующий GitHub / Render

1. Скачай архив `AntiScam_v0.8_обновление_GitHub.zip`, распакуй.
2. Открой https://github.com/AlexanderHedlund-prog/AntiScam.
3. **Add file → Upload files**, загрузи содержимое архива **изнутри папки**, сохранив структуру `app/...` и `tests/...`, и нажми **Commit changes**. Не загружай архив ZIP как один файл.
4. Дождись автоматического развёртывания в Render до **Live**. Если не началось, вручную нажми **Deploy latest commit**.
5. Открой https://antiscam-xj4u.onrender.com/health. Должно быть `version: 0.8.0`.
6. Открой `/file` и загрузи свой безобидный документ. «Собственный анализ AntiScam» должен быть выполнен, а ClamAV — **не подключён**, если отдельный движок ещё не установлен.

`requirements.txt` и существующие API-ключи VirusTotal/Google менять не требуется. **Никогда не добавляй настоящие ключи в публичный GitHub**.

## Локальный запуск / тесты

Python 3.11+:

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Тесты:

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```

## Безопасность и конфиденциальность

- На Render файл ограничен 8 МБ, временно считывается в память, не исполняется и не пересылается целиком VirusTotal. Веб-сервер/фреймворк могут использовать временные буферы. Не загружай секретные документы.
- Никакого запуска чужих файлов и неизвестного JavaScript. Локальные проверки применяются с ограничениями объёма данных.
- Положительные статические признаки не доказывают заражение; отсутствие признаков не доказывает безопасность.
- На публичном сайте остаются риски злоупотреблений и ресурсоёмких архивов; до массового использования нужен независимый аудит загрузок, Rate Limit, WAF и процесса изоляции.

Источники: https://docs.clamav.net/ ; https://docs.clamav.net/manual/Usage/ClamdProtocol.html
