# AntiScam v1.1 — VirusTotal: новое сканирование файлов и согласие

Бесплатный образовательный сервис для предварительной проверки ссылок и файлов. Сайт: https://antiscam-xj4u.onrender.com/ (адрес вашего существующего развёртывания).

## Что изменилось

- Если пользователь включает **поиск отчёта по SHA-256**, AntiScam ищет уже существующий отчёт VirusTotal без отправки полного файла.
- Если отчёта нет, функция нового сканирования при включении владельцем **передаёт полный файл в VirusTotal только после двух отдельных действий пользователя**: выбор нового анализа и подтверждение соглашения.
- `/agreement` — страница соглашения о приватности, ограничениях и возможной доступности образцов участникам сообщества VirusTotal.
- По успешной загрузке VirusTotal возвращает `analysis_id`, а AntiScam — одноразовый подписанный токен ожидания. Он работает **после перезапуска Render в течение 24 часов** при неизменном ключе VirusTotal. Подделать токен без серверного секрета нельзя.
- Кнопка **«Узнать результат»** обращается к `/api/vt-file-status`. Сайт различает «ещё проверяется», «достигнут лимит», «готовый отчёт» и ошибку. Предварительно запрос выполняется после паузы 45 секунд, чтобы не расходовать лимит слишком быстро.
- В итоговом отчёте число движков считается только из систем, давших результат. Тайм-ауты и неподдерживаемые форматы учитываются отдельно. Нулевое число находок **не гарантирует безопасность**.
- Локальный анализатор, проверка URL, Google Safe Browsing и дизайн сохранены.

## Как обновить существующий GitHub + Render

1. Сохраните резервную копию проекта. Распакуйте архив `AntiScam_v1.1_обновление_GitHub.zip`.
2. Откройте https://github.com/AlexanderHedlund-prog/AntiScam, **Add file → Upload files**.
3. Загрузите **содержимое** распакованного архива в корень репозитория с сохранением папок `app/`, `tests/`. Новые файлы должны заменить существующие.
4. Нажмите **Commit changes**. Дождитесь в Render статуса **Live**.
5. Откройте https://antiscam-xj4u.onrender.com/health: версия должна быть `1.1.0`.
6. В Render → AntiScam → Environment проверьте существующие переменные:
   - `VIRUSTOTAL_API_KEY` — **ваш действующий секретный ключ**, не отправляйте его в GitHub и чат.
   - `VT_FILE_UPLOAD_ENABLED=true` — включить кнопку нового сканирования только если условия VirusTotal разрешают использование (поддержка уже подтвердила условно разрешённое некоммерческое использование).
   - `VT_STATUS_SIGNING_KEY` — **необязателен**: отдельный длинный случайный секрет для подписи токенов. Если не задан, применяется производный ключ от действующего `VIRUSTOTAL_API_KEY`. При смене любого из секретов старые токены станут недействительны.
7. Вкладка «Проверить файл» → собственный **неконфиденциальный** тестовый файл до 8 МБ → поставить галочки «Искать... по SHA-256», «Если отчёта нет...», «Я прочитал(а) соглашение» → «Проверить файл».
8. Если файл был принят VirusTotal, дождитесь 45–60 секунд и нажмите «Узнать результат». При лимите HTTP 429 подождите минимум минуту. При `pending` **не отправляйте этот же файл заново**.

**Не проверяйте личные фото, документы с ФИО, паролями или конфиденциальную информацию** новой отправкой: обычная загрузка в VirusTotal может сделать файл доступным другим сторонам. Внешнее сканирование может не дать отчёта или пропустить новые угрозы.

## Как работает API

- `POST /api/scan-file` — multipart `file`, `check_hash=true|false`, `submit_to_vt=true|false`, `vt_public_consent=true|false`. На сервере файл не выполняется.
- `POST /api/vt-file-status` — JSON `{"token":"<подписанный токен>"}`, не передавайте token третьим лицам.
- `GET /api/providers` — признак, настроены ли интеграции (ключи не раскрываются).
- `GET /health` — технический статус.

## Лимиты и безопасность

- Загрузка файла максимум **8 МБ**, несколько одновременных анализов ограничены.
- VirusTotal Public API ограничен по запросам, включая поиск по хешу, отправку и получение результатов. В приложении не более 3 запросов в минуту на один процесс, до 8 новых отправок в сутки на процесс. Эти ограничения **не являются глобальной распределённой квотой**: в многоэкземплярной системе потребуется Redis/БД и внешний WAF.
- На Render Free приложение может заснуть и перезапуститься. Подписанные токены ожидания не привязаны к памяти процесса, но пользователь должен оставить вкладку открытой до получения результата.
- Изменение VT API ключа аннулирует токены, если не установлен постоянный `VT_STATUS_SIGNING_KEY`.
- Всё ПО работает как предварительный анализатор угроз, **не заменяет антивирус**. Для публичного сервиса рекомендуется независимый security audit.

## Разработка и локальные тесты

```bash
pip install -r requirements.txt
pip install -r requirements-dev.txt
python -m pytest -q
uvicorn app.main:app --reload
```

В автоматических тестах ответы VirusTotal имитируются, **реальный API-ключ не используется и настоящие файлы в VirusTotal не отправляются**.
