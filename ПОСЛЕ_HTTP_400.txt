AntiScam v0.3.3 — что делать после ошибки Google HTTP 400

1. В GitHub загрузите содержимое этого архива поверх старых файлов, сохраняя структуру: app/scanner.py и app/main.py должны находиться в папке app, requirements.txt — в корне.
2. Нажмите Commit changes.
3. Дождитесь автоматического Deploy на Render (или Manual Deploy → Deploy latest commit).
4. Проверьте https://antiscam-xj4u.onrender.com/health — версия должна быть 0.3.3.
5. На https://antiscam-xj4u.onrender.com/ проверьте публичную https://example.com, подтвердив передачу URL внешним сервисам.
6. Если снова Google HTTP 400, посмотрите текст рядом с Google Safe Browsing: мы добавили конкретные диагностические сообщения.
7. В https://console.cloud.google.com/apis/credentials проверьте ключ: создан для нужного проекта, Safe Browsing API включён и разрешён в API restrictions, Application restrictions совместимы с серверным Render (не Website/HTTP referrers).

Никогда не помещайте ключи в GitHub и не присылайте ключи или страницы, где ключ виден, в чат.
Не нужно повторно создавать Render Web Service.
