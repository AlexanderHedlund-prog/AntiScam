АНТИСКАМ — САЙТ ДЛЯ ПРОВЕРКИ ССЫЛОК И ФАЙЛОВ
Версия для компьютера, исходный код для GitHub и Render

ВАЖНО: сайт не является полноценным антивирусом. Если в результатах написано
«не обнаружены известные угрозы», это не означает, что ссылка или файл безопасны.
Реальная проверка репутации по внешним базам требует API-ключей.

1. КАК ОТКРЫТЬ САЙТ У СЕБЯ НА WINDOWS

1) Распакуй скачанный ZIP через «Извлечь все».
2) Открой папку AntiScam.
3) Установи Python 3.11+ с https://www.python.org/downloads/ (если Python ещё нет).
4) Дважды нажми START_ANTISCAM_WINDOWS.bat.
5) Подожди установки библиотек (в первый раз нужен интернет).
6) Открой http://127.0.0.1:8000 в браузере.
7) Пока сайт работает, НЕ закрывай окно терминала.

Не запускай app/static/index.html напрямую: проверка ссылок и файлов требует Python-сервер.

2. КАК ЗАГРУЗИТЬ ПРОЕКТ В GITHUB ЧЕРЕЗ БРАУЗЕР НА КОМПЬЮТЕРЕ

1) Войди в https://github.com/.
2) Открой https://github.com/new.
3) В поле «Repository name» напиши antiscam.
4) Выбери «Public» (если хочешь открытый исходный код).
5) Нажми «Create repository» (лучше пока не добавлять README и .gitignore).
6) На компьютере открой РАСПАКОВАННУЮ папку AntiScam.
7) Выдели ВСЁ содержимое этой папки: папки app и tests и остальные файлы.
8) Перетащи выделенное прямо в окно GitHub «uploading an existing file»
   или в раздел «Add file» -> «Upload files». Переносить нужно НЕ ZIP, а файлы.
9) Дождись окончания загрузки, введи сообщение коммита «Initial AntiScam»
   и нажми «Commit changes» (или «Propose changes», если так называется кнопка).
10) Проверь: в корне репозитория должны быть app/, requirements.txt,
    render.yaml, README.md. НЕ должно быть лишней внешней папки AntiScam/.

ВАЖНО: НЕ загружай папку .venv, личный файл .env или любые API-ключи.
Они специально исключены в .gitignore, но при загрузке через браузер
проверяй выбранные файлы самостоятельно.

3. КАК ПОЛУЧИТЬ НАСТОЯЩУЮ ССЫЛКУ НА САЙТ

GitHub хранит код, но не запускает Python-сервер через GitHub Pages.
Для сайта со сканированием файлов используй веб-хостинг (например Render).

1) Открой https://render.com/ и войди в аккаунт.
2) Выбери «New» -> «Web Service».
3) Подключи GitHub и выбери репозиторий antiscam.
4) В настройках задай:
   Language/Runtime: Python
   Root directory: (оставь пустым)
   Build command: pip install -r requirements.txt
   Start command: uvicorn app.main:app --host 0.0.0.0 --port $PORT --no-access-log
5) Выбери доступный тариф, например Free, если он предлагается.
6) Нажми «Deploy Web Service» / «Create Web Service».
7) Подожди сообщения об успешной публикации.
8) Render выдаст твой личный адрес вида https://ИМЯ.onrender.com.
   Для проверки открой /health, /, /file.

Для проверки известных угроз настрой GOOGLE_SAFE_BROWSING_API_KEY и
VIRUSTOTAL_API_KEY в настройках переменных окружения на Render.
НЕ записывай ключи в GitHub и не публикуй их в переписке.

ПЕРЕД ПУБЛИЧНОЙ РЕКЛАМОЙ: проект остаётся тестовым. Нужна независимая
проверка безопасности приёма файлов, настройка ограничений на стороне
хостинга, отслеживание злоупотреблений и соблюдение правил API.
