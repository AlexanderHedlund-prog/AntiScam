AntiScam v0.3.4 — минимальный запрос к Google Safe Browsing v5

Причина HTTP 400 пока не подтверждена. Это диагностическое изменение:
удалён дополнительный query-параметр alt=json, который не нужен для вызова urls.search.
Запрос остаётся GET https://safebrowsing.googleapis.com/v5/urls:search
с параметрами key и urls; заголовок Accept: application/json сохранён.

ОБНОВЛЕНИЕ ЧЕРЕЗ GITHUB:
1. Распакуйте файл исправления.
2. Загрузите файлы app/scanner.py и app/main.py в корень репозитория
   с сохранением структуры app/ (или все файлы из полного архива).
3. Commit changes.
4. Дождитесь Live в Render (при необходимости Deploy latest commit).
5. На /health проверьте версию 0.3.4.
6. На сайте проверьте https://example.com, разрешив внешнюю проверку.
7. Если 400 повторится — нужно увидеть безопасно обезличенную диагностическую
   информацию из ответа Google; не показывайте ваш API-ключ.

Новый ключ в Google Cloud и новые переменные Render не требуются.
