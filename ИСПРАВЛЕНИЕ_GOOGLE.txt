ANTI SCAM — исправление Google Safe Browsing, версия 0.3.2

Что исправлено:
1. В запрос Google v5 добавлен параметр alt=json. Теперь ожидается JSON, а не двоичный ответ по умолчанию.
2. Вместо общей ошибки показываются отдельные категории: HTTP 401/403, 429, тайм-аут, сеть, некорректный ответ.
3. Если VirusTotal не нашёл угроз, но Google не ответил, результат больше НЕ будет зелёным: появится «Проверка выполнена частично».

Публикация обновления:
1. Открой https://github.com/AlexanderHedlund-prog/AntiScam
2. Самый надёжный способ обновить существующий проект: GitHub Desktop (https://desktop.github.com), File -> Clone repository, выбрать AntiScam.
3. Распакуй этот ZIP; СКОПИРУЙ ЕГО СОДЕРЖИМОЕ поверх файлов в папку клонированного проекта, сохраняя пути app/scanner.py и app/main.py.
4. В GitHub Desktop: Commit to main -> Push origin.
5. Render обычно автоматически сделает новый Deploy. Проверить статус Live и https://antiscam-xj4u.onrender.com/health — версия 0.3.2.
6. На https://antiscam-xj4u.onrender.com/ выполни проверку https://example.com с согласием на внешние проверки.
7. При ошибке Google пришли скриншот ТОЛЬКО сообщения об ошибке. Не присылай API-ключи.

Для браузерного способа загрузки, если GitHub позволяет перезаписать файлы:
  Add file -> Upload files -> перетащить все файлы/папки из распакованного ZIP
  (пути должны начинаться с app/ и tests/, без лишней папки AntiScam).
Если GitHub не разрешает заменить существующий файл, используй GitHub Desktop.

ВАЖНО: не загружай .env с API-ключами, и не копируй ключи в исходники. Исправление не гарантирует устранения ошибок, вызванных ограничениями ключа в Google Cloud или сбоями сети.
